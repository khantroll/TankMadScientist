How to set an API key

On each OpenAI-compatible or Tank-controlled provider, the API key field is a password box. Save writes a filled value to api_key_default in providers.local.yaml next to providers.yaml. That file is gitignored. The tracked providers.yaml never receives the secret, and this page does not show the stored value again. A blank field leaves the stored key unchanged.

Save reloads provider config in this process. Test and new runs then use the key. An environment variable named by api_key_env still wins when it is actually set. You do not need to restart Tank for these providers.

You can still set the variable in the environment instead of using the field: 

# PowerShell
$env:MISTRAL_API_KEY = "..."
$env:OPENROUTER_API_KEY = "..."

# bash
export MISTRAL_API_KEY="..."

On Windows, persist a user variable from System Properties → Environment Variables if you prefer that over the local file. providers.local.yaml can also hold a machine-only model or base URL. The only api_key_default allowed in the tracked providers.yaml is lm-studio.
