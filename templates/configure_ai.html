How to set an API key

Tank reads the variable named by api_key_env. The secret is never written to providers.yaml. Set it in the environment, then restart Tank so this process sees it. Test checks that the endpoint accepts the key. 

# PowerShell
$env:MISTRAL_API_KEY = "..."
$env:OPENROUTER_API_KEY = "..."

# bash
export MISTRAL_API_KEY="..."

On Windows, persist a user variable from System Properties → Environment Variables. Optional machine-only overrides belong in providers.local.yaml next to providers.yaml. That file is gitignored. Use it for a local model or base URL. A literal key does not belong in the tracked file. The only api_key_default allowed there is lm-studio. If you must keep a literal off-git, put api_key_default in providers.local.yaml only.
